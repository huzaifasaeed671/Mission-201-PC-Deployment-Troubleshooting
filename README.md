# Windows PC Deployment, Configuration & Troubleshooting

## Project Overview
This project documents a practical Windows PC assessment, configuration review, performance monitoring, system diagnostics, recovery tools investigation, and troubleshooting scenarios.

The work was performed on a physical Windows computer to explore real-world IT Support and Desktop Support tasks without creating a resource-heavy virtual machine.

## Objectives
- Inspect Windows system specifications and hardware.
- Review storage, disk partitions, and device drivers.
- Investigate Windows Update and startup applications.
- Monitor CPU, memory, and disk performance.
- Explore Windows services and system logs.
- Understand Windows recovery and troubleshooting tools.
- Investigate common PC troubleshooting scenarios.

## Practical Work
- System Information
- Windows Settings and System Configuration
- Device Manager
- Disk Management
- Task Manager
- Resource Monitor
- Event Viewer
- Services
- Windows Recovery Options
- Storage and performance investigation

## Troubleshooting Scenarios
1. Slow Computer Performance
2. Boot Failure Troubleshooting
3. Missing Driver Troubleshooting
4. Low Disk Space
5. Application Crash Investigation
6. Windows Service Troubleshooting

## Repository Structure
- `Documentation/` — Detailed project documentation.
- `Screenshots/` — Evidence of investigations and system configuration.

## Learning Outcomes
Developed practical familiarity with Windows system tools, hardware and software investigation, performance monitoring, troubleshooting methodology, system logs, and recovery options.

## Disclaimer
This project involved safe inspection and simulated troubleshooting scenarios. No intentional system failures, driver removals, destructive disk operations, or unnecessary service modifications were performed.
